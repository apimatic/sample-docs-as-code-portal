This developer portal is built by the APIMatic CLI from the OpenAPI document in
this repository. The same platform turns any OpenAPI specification into a
complete developer experience.

## AI-ready API context

Context plugins load your full API context, docs, SDKs, code samples and setup
instructions, into AI coding environments such as Claude Code and Cursor, so
developers integrate your API through natural language instead of a wall of
reference docs.

## SDK and API documentation

API reference documentation with language-specific docs and SDK guides,
including idiomatic, ready-to-run code samples across all seven SDK languages.
Developers can explore your API before writing any code.

## Live API playground

A built-in testing interface supporting all major authentication methods.
Developers make real API calls, see actual responses, and validate their
integration approach.

## Multi-language SDKs

Production-ready client libraries in Java, Python, TypeScript, C#, PHP, Ruby
and Go. Each SDK includes documentation and code samples, and follows the
conventions of its language.

## Ready to build your own?

Start at [apimatic.io](https://www.apimatic.io) or run `npx @apimatic/cli quickstart`.
