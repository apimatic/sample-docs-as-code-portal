Welcome to the documentation. The **API Reference** tab describes every endpoint, and the
**SDKs** tab has a client library for each language.

Replace this page with your own introduction, and add more Markdown pages beside it.
`nav.json` in the same folder sets the order they appear in.

## What APIMatic offers

This portal was built by the **APIMatic CLI** from the OpenAPI document in `src/spec/`. The
same command turns any specification into a portal like this one: reference documentation,
SDKs in several languages, a request console on every operation, and the context an AI
coding assistant needs to write working integration code.

## Questions

### How quickly can we launch a portal?

In minutes. `apimatic quickstart` scaffolds this directory from an OpenAPI document,
`apimatic portal serve` previews it as you edit, and `apimatic portal generate` writes a
static site you can host anywhere.

### How does the portal stay current as the API changes?

Everything is built from `src/`, so updating the specification and running
`portal generate` again republishes every reference page, code sample and SDK. Your own
Markdown pages and your settings in `apimatic.json` are left alone.

### How much can we customize?

The `portal` block of `apimatic.json` carries the site name and address, the logo, favicon,
primary colour and colour mode, and the header links. Markdown pages under `src/content/`
become documentation pages, and each `nav.json` sets the order, the folder titles, and
which folders become tabs.

### Where can we host it?

`portal generate` produces plain static files. Serve them from GitHub Pages, Netlify,
Cloudflare Pages, S3 behind a CDN, or any web server. Point unknown paths at `404.html`
and nothing else needs configuring.

### What can AI tools do with this portal?

Context Plugins connect your API to the assistant a developer already uses, so it answers
questions and writes integration code from your specification rather than from guesses.
Each page also offers its Markdown source, and the portal publishes `llms.txt` and
`llms-full.txt` for tools that read a whole site at once.
